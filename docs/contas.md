# Contas para criar antes da primeira aula

Crie as contas com calma, em casa, antes do primeiro sábado. Criar conta é grátis em todos os sites abaixo; pagamento, só onde estiver indicado.

Dicas:

- Use o mesmo e-mail em todos os sites e guarde as senhas num lugar seguro (o gerenciador de senhas do Chrome serve).
- Ative a verificação em duas etapas onde o site oferecer.
- Chave de API é como senha de banco: nunca mande por WhatsApp nem cole em grupo.

## 2. Opcionais: o caminho econômico (API pré-paga)

Para usar a IA pagando só o que gastar, em vez de assinatura. Precisa de **cartão de crédito internacional**. Crie a conta, mas não coloque créditos antes da aula 1: o caminho econômico é explicado no primeiro sábado. Preços em [ferramentas e custos](ferramentas-e-custos.md).

| Site | Para quê |
|---|---|
| [platform.deepseek.com](https://platform.deepseek.com) | DeepSeek: das IAs mais baratas para o agente |
| [platform.xiaomimimo.com](https://platform.xiaomimimo.com) | Xiaomi MiMo: também muito barata |
| [openrouter.ai](https://openrouter.ai) | Uma carteira só para centenas de IAs (cobra 5,5% na recarga) |
| [aistudio.google.com](https://aistudio.google.com) | Gemini, do Google, com a mesma conta do Gmail: imagens (Nano Banana) e narração por voz de IA sem assinatura. Para o agente pensar, sai mais caro que DeepSeek e MiMo |
